# Citing RTsegmentator

Cite the RTsegmentator version you used and the DOI archived for that release. The
repository's [`CITATION.cff`](https://github.com/kstawiski/rtsegmentator/blob/main/CITATION.cff)
holds the machine-readable metadata; GitHub's "Cite this repository" button formats it.

Every contour comes from a third-party model. Cite each model's own publication and
follow its licence. The `reference`, `license` and `limitations` fields of each model
in the [result manifest](result-manifest.md), the [model catalog](models.md) and the
[model ledger](external-models.md) identify them.

A methods section can report, for each model, the RTsegmentator version, the task
name, the model reference, and the portal's technical checks (see
[technical checks](validation.md)). Keep the result manifests: they record the job,
the source series, the exact ROI names and the checksums of the files you analysed.
