# Security policy

Do not submit identifiable clinical data to a public demo. Deploy behind TLS,
access control and an appropriate institutional data boundary.

Please report vulnerabilities privately to the repository maintainer rather
than opening a public issue. Do not include patient data, credentials, model
license keys or production logs containing identifiers in a report.

RTsegmentator is research software and is not intended for unattended clinical
decision-making or direct treatment planning.
