# Code of conduct

RTsegmentator follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Participants commit to respectful, harassment-free collaboration in issues, pull
requests, reviews and any other project space.

Report unacceptable behaviour privately to the project maintainers through
GitHub's private reporting channel for this repository. Do not include patient
data, credentials or production logs in a report. Maintainers review every report,
keep the reporter's identity confidential and may remove contributions or block
participants who breach this code.
